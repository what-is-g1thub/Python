# Лабораторная работа 3

## Состав папки

- `minimum.py` - минимум трёх чисел
- `calculator.py` - калькулятор
- `point.py` - принадлежность прямоугольнику

## Как запустить

Для каждого файла:

    python minimum.py
    python calculator.py
    python point.py
    python variant.py
    python year.py

Если команда `python` не работает, используйте `py` или `python3`.

## Пояснения

- **`=` и `==`:** `=` присваивает значение, `==` сравнивает. В условиях используется `==`.
- **`and` и `or`:** `and` требует истинности обоих условий (например, точка внутри прямоугольника), `or` — хотя бы одного (например, выход за диапазон).
- **Двойное неравенство:** `0 <= x <= 5` равносильно `0 <= x and x <= 5`, границы включаются.
- **Порядок ветвей:** в цепочке `if`/`elif`/`else` выполняется только первая подходящая ветвь. Поэтому границы категорий проверяются по возрастанию: сначала `<= 19`, затем `<= 79`, иначе `Высокий`.
- **Границы включены:** при значении ровно на пороге (59, 60, 89, 90) срабатывает та категория, в которую порог входит по условию задачи.
- **Деление на ноль:** проверяется до самого деления, иначе программа завершится с ошибкой `ZeroDivisionError`.
- **Високосный год:** условие `year % 400 == 0 or (year % 4 == 0 and year % 100 != 0)` учитывает все три правила григорианского календаря.
- **Формат вывода:** `:.2f` выводит два знака после точки, округляя по правилам Python.
- **Типы данных:** `int(input())` для целых чисел, `float(input())` для вещественных; `input()` без преобразования возвращает строку.
