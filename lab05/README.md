# Лабораторная работа 5. Обработка строк (вариант 11)

## Запуск
    python normalize.py
    python palindrome.py
    python replace.py
    python variant.py
    python palindrome_loop.py

## Проверки
### normalize.py
- `  Один   два  ` → длина исходная 14, новая 8, текст `Один два`, слов 2
- пустая строка → длина 0, слов 0

### palindrome.py
- `А роза упала на лапу Азора` → Палиндром
- `а    ` → Палиндром (пробелы убраны)
- `     ` → Нет текста
- `Python` → Не палиндром
- `А!` → Не палиндром (пунктуация сравнивается как есть)

### replace.py
- `a::b:` → замен 3, `a--b-`
- `abc` → замен 0, `abc`

### variant.py (вариант 11: длина 3..5)
- `Анна, армия! Я читаю.` → анна, армия, читаю; количество 3
- `!!!` → Нет совпадений, количество 0
- пустой ввод → Нет совпадений, количество 0

### palindrome_loop.py
Результаты совпадают с palindrome.py на всех тестовых входах.

## Ответы на вопросы защиты
- Строки неизменяемы: text.lower() возвращает новую строку, исходная не меняется.
- Слово — элемент, полученный split(); подстрока — любая часть строки (может быть внутри слова).
- Правила обработки пунктуации задаются до реализации, иначе невозможно однозначно определить, что считать словом и как сравнивать палиндром.
