# Лабораторная работа 1

## Состав папки

- `hello.py` - первая программа
- `profile.py` - карточка студента
- `workload.py` - учебная нагрузка

## Как запустить

Для каждого файла:

    python hello.py
    python profile.py
    python workload.py
    python debug.py
    python swap.py
    python variant.py

Если команда `python` не работает, используйте `py` или `python3`.

### debug.py

**Фрагмент А:**

- Было: `first = "2"`, `second = "3"`, вывод `23`
- Причина: строки соединяются, а не складываются
- Исправление: преобразовать в `int`
- Ожидаемый результат: `5`
- Фактический результат: `5`
- Типы до: `str`, `str`; после: `int`, `int`

**Фрагмент Б:**

- Ввод: `17`
- Было: `age + 1` - ошибка `TypeError`
- Причина: `input()` возвращает строку
- Исправление: `age = int(input("Возраст: "))`
- Ожидаемый результат: `18`
- Фактический результат: `18`
- Тип до: `str`; после: `int`

**Фрагмент В:**

- Было: `average = first + second + third / 3` — деление только `third`
- Причина: нарушен порядок операций
- Исправление: `average = (first + second + third) / 3`
- Ожидаемый результат: `7.0`
- Фактический результат: `7.0`

**Дополнительная проверка:** заменили числа на `1`, `2`, `3`, пересчитали вручную, результат `2.0` совпал.

### variant.py

**Мой вариант:** №11 - Магазин растений. Первая позиция - Саженцы, вторая позиция - Горшки.

**Пример заказа:**

- Название заказа: Магазин растений
- Имя заказчика: Михаил
- Позиция 1: Саженцы, 3 шт., 12.50 руб.
- Позиция 2: Горшки, 2 шт., 20.00 руб.
- Доставка: 10.00 руб.
- Скидка: 10%
- Внесено: 100.00 руб.

**Ручной расчёт до запуска:**

- Стоимость позиции 1: 3 × 12.50 = 37.50
- Стоимость позиции 2: 2 × 20.00 = 40.00
- Товары без доставки: 37.50 + 40.00 = 77.50
- Скидка 10%: 77.50 × 10 / 100 = 7.75
- Товары со скидкой: 77.50 − 7.75 = 69.75
- Всего с доставкой: 69.75 + 10.00 = 79.75
- Общее количество: 3 + 2 = 5
- Сдача: 100.00 − 79.75 = 20.25

## Пояснения

- **Строка и число:** `input()` всегда возвращает строку. Строка - это просто текст. Для вычислений нужно `int()` или `float()`.
- **Порядок вычислений:** сначала умножение и деление, потом сложение и вычитание; скобки меняют порядок.
- **Временная переменная при обмене:** нужна, чтобы не потерять одно из значений.
- **Форматирование денег:** `:.2f` выводит два знака после точки.
