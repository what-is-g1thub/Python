### predictions.py

**Что проверяли:** порядок выполнения арифметических операций и поведение `//` и `%` для отрицательных чисел.

**Прогноз до запуска:**

| Выражение | Прогноз | Результат Python | Совпало? |
|---|---|---|---|
| `2 + 3 * 4` | `14` | `14` | да |
| `(2 + 3) * 4` | `20` | `20` | да |
| `17 // 5` | `3` | `3` | да |
| `17 % 5` | `2` | `2` | да |
| `-7 // 2` | `-4` | `-4` | да |

**Объяснение различий:** различий не возникло. В первом выражении умножение выполняется раньше сложения. Скобки во втором выражении меняют порядок. `//` - деление с округлением вниз, поэтому `-7 // 2` даёт `-4`, а не `-3`. Остаток `17 % 5` равен `2`, так как `17 = 3 * 5 + 2`. Для отрицательных чисел равенство `a == (a // b) * b + a % b` также выполняется: `-7 == (-4) * 2 + 1`.

**Фактический результат:** совпадает.

## Пояснения

- **Отличие `/` от `//`:** `/` всегда возвращает `float`, даже при делении нацело (`10 / 2 == 5.0`). `//` возвращает целую часть с округлением вниз (`10 // 3 == 3`, `-7 // 2 == -4`).
- **Смысл остатка:** `a % b` — это то, что остаётся после выделения максимального кратного `b`. Для неотрицательных чисел это «остаток от деления». Для отрицательных работает то же правило: `-7 % 2 == 1`, так как `-7 = (-4) * 2 + 1`.
- **Неточность `float`:** многие десятичные дроби хранятся приближённо. Например, `0.1 + 0.2` даёт `0.30000000000000004`. Формат `:.2f` меняет только вывод, а не само хранимое число.
- **Минимальное число единиц:** формула `(total + capacity - 1) // capacity` работает без условий и циклов. При `total = 0` она даёт `0`, что соответствует требованию.
- **Скобки:** явно задают порядок вычислений и делают выражение понятнее.
