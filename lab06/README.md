# Лабораторная работа 6. Списки (вариант 11)

## Запуск
    python statistics.py
    python transform.py
    python positions.py
    python variant.py
    python unique.py

## Проверки
### statistics.py
- `-2 0 5 3` → количество 4, сумма 6, min -2, max 5, среднее 1.50
- `8` → 1, 8, 8, 8, 8.00
- пустой ввод → `Нет данных`

### transform.py
- `-2 0 5 -2` → исходный `[-2, 0, 5, -2]`, новый `[2, 0, 5, 2]`
- пустой ввод → `[]` и `[]`

### positions.py
- `7 7` → `[0, 1]`
- `-3 -1 -2` → `[1]`
- пустой ввод → `Нет данных`

### variant.py (вариант 11: |n| <= 3)
- `-8 -3 0 6 6 1` → `[-3, 0, 1]`, количество 3, сумма -2, сортировка `[-3, 0, 1]`
- непустой дополнительный пример: `-2 4 -3 0 5` → `[-2, -3, 0]`, 3, -5
- пустой ввод → `[]`, 0, 0, `[]`

### unique.py
- `3 1 3 2 1` → `[3, 1, 2]`
- `1 1 1` → `[1]`

## Ответы на вопросы защиты
- append() добавляет элемент в конец, присваивание по индексу заменяет существующий.
- sorted() возвращает новый список, sort() сортирует на месте и возвращает None.
- Исходный список в transform.py не изменяется: создаётся новый result.
